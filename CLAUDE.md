# CLAUDE.md

Автоматический дайджест о фитнесе, бодибилдинге и здоровом образе жизни на Astro + Vercel. Проект курса Claude Code Basics.

Общие правила лежат в `.claude/rules/`: критичные подключены через `@` и действуют всегда, справочные читаются по ссылке. Правила написания статей лежат рядом со статьями и поднимаются только при работе с ними.

## Редполитика

Тематика, стиль, формат и структура статьи — в `src/content/blog/CLAUDE.md`. Файл поднимается автоматически при работе со статьями, отдельного импорта не требует.
