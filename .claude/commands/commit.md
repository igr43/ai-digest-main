# /commit

Собери коммит по формату Conventional Commits. Подтверждение обязательно.

## Действия

1. Покажи `git status --short` и `git diff --stat`. Если менять нечего — скажи об этом и остановись.
2. Прочитай сам диф (`git diff`, для staged — `git diff --cached`), чтобы понять суть изменений. Сообщение пишется по содержимому, а не по именам файлов.
3. Если ничего не в индексе — добавь файлы, относящиеся к одной задаче. Не подмешивай посторонние правки: разные задачи — разные коммиты.
4. Составь сообщение по формату ниже.
5. Покажи готовое сообщение и список файлов. **Спроси подтверждение и дождись ответа.** Без явного «да» не коммить.
6. После подтверждения выполни коммит и покажи SHA.

## Формат

```
тип(область): описание

Тело: зачем изменение, если из описания неочевидно. Строки до 72 символов.

Co-Authored-By: <строка атрибуции из инструкций Claude Code>
```

Строку `Co-Authored-By` не выдумывай и не копируй из старых коммитов: модель меняется, бери актуальную из системных инструкций.

**Типы:**

- `feat` — новая функциональность или новая статья.
- `fix` — исправление ошибки.
- `docs` — документация: `README.md`, `CLAUDE.md`, комментарии.
- `refactor` — правка кода без изменения поведения.
- `test` — тесты.
- `chore` — рутина: зависимости, конфиги, служебные файлы, пайплайны.

**Области:** `blog` (статьи), `layout` (шаблоны и компоненты), `config` (конфиги Astro и проекта), `agents` (субагенты и команды), `hooks` (хуки), `deps` (зависимости). Если правка шире одной области — скобки опускаются.

## Правила

- Первая строка целиком — до 72 символов, считая тип и область.
- Описание с маленькой буквы, в повелительном наклонении, без точки в конце.
- Язык описания — русский. Тип и область — латиницей.
- Ломающее изменение: `!` перед двоеточием (`feat(config)!: ...`) плюс футер `BREAKING CHANGE: <что сломалось>`.
- Запрещены `git push --force`, `git reset --hard`, `git commit --amend`.
- Прямой коммит и push в `main` не делать — работа идёт в ветках.

## Примеры

```
feat(blog): добавить шаблон статьи для дайджеста
fix(layout): показывать обложку из поля cover
docs: описать формат Conventional Commits
chore(deps): обновить astro до 6.1.1
```
