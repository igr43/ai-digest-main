# Git

- Ветка по умолчанию `main`.
- Прямой push в `main` блокирует PreToolUse-хук `.claude/hooks/block-main-push.sh`. Автоматика коммитит в ветку `digest/auto`, слияние в `main` — вручную по желанию.
- Запрещены `git push --force`, `git reset --hard`, `git commit --amend`.

## Формат коммитов

Conventional Commits: `тип(область): описание`. Действует для всех коммитов — ручных, через `/commit` и от субагентов.

- Типы: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`.
- Области: `blog`, `layout`, `config`, `agents`, `hooks`, `deps`. Если правка шире одной области — скобки опускаются.
- Первая строка до 72 символов целиком. Описание с маленькой буквы, в повелительном наклонении, без точки.
- Язык описания — русский, тип и область — латиницей.
- Ломающее изменение: `!` перед двоеточием плюс футер `BREAKING CHANGE:`.

Пример: `feat(blog): добавить шаблон статьи для дайджеста`.

## Ветки и PR

- Имя ветки: `тип/краткое-описание`. Тип — из списка выше, описание латиницей через дефис. Пример: `chore/commit-convention`. Исключение — `digest/auto`, ветка автоматики.
- PR всегда в `main`. Ветки `develop` в проекте нет.
